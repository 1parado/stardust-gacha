# 角色立绘放这里

## 命名规则

文件名就是卡的 `id`。卡 id 在 `js/core.js` 里生成，规则是 `稀有度 + 序号`：

```
N1 … N12       常见
R13 … R36      稀有
SR37 … SR52    超稀有
SSR53 … SSR60  传说
EX61           至臻 · 无相（唯一）
```

当前目录里 **61 张 `.webp` 已全部就位**。旁边的 `.svg` 是占位图，不在探测列表里，不会被使用。

## 支持的格式

运行时按顺序探测：**`.webp` → `.avif` → `.png` → `.jpg`**，第一个能解码成功的就用它。

建议用 `webp`（体积和兼容性平衡最好）。同一个 id 放多个格式也可以。
先请求 webp 是因为当前资产全是 webp——放在首位可以命中即停，避免每张卡都先吃一个 404。

## 尺寸

- 推荐 **768 × 1075**（比例 1 : 1.4，和卡面一致）
- 主体人物居中偏上，**底部留出约 25% 的空间**——那里有渐变遮罩和角色名
- 手机端会按容器缩放，所以给到 1000px 宽也够，不必更大

## 不需要改代码

放进去就生效。加载失败的卡会自动退回几何徽记，不会出现破图。

新增一张卡时逐个格式探测，确认缺失后会被记入 `artMissing`，之后的渲染不再重复请求。

## 换图 / 重新生成

原始 1024 × 1536 PNG 在 `cards-art/`，文件名是 `{卡号}_{卡名}.png`。
需要重新转换时执行：

```powershell
node tools/build-art.mjs
```

## 快速预览

想先看看有图的效果，可以生成一批占位图：

```powershell
node tools/gen-placeholder-art.mjs
```

它会给每张卡画一张带渐变背景和编号的占位图（纯 Node 实现，不需要额外依赖）。
不满意就直接删掉 `assets/cards/*.svg`——`.svg` 不在探测列表里，不会被使用。

> 注意：占位图脚本如果生成 `.webp` 会被真实加载。如果只是预览，跑完记得删掉。
